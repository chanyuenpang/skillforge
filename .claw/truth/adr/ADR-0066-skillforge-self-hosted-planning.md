# ADR-0066: SkillForge Self-Hosted Planning 默认推进链路

- Status: Accepted
- Date: 2026-05-26
- Deciders: 项目负责人

## Context

在 SkillForge 的自举试跑中，团队已分别沉淀了两类核心文档：

- 规则层：`docs/skillforge-execution-rules-v1.md`
- Workflow 层：`docs/skillforge-execution-workflow-v1.md`

当前需要明确“后续推进项目时的默认链路”，以统一从任务意图到执行派发前的治理路径。此前实践里存在“直接裸 spawn”或“边做边补文档”的做法，虽然速度快，但在复杂任务中容易出现目标漂移、上下文断裂、以及复盘困难。

因此需要一个 ADR 级别的统一裁决，明确默认推进方式、适用边界、例外条件与文档接口关系。

## Decision

### 1) 默认推进链路（负责人裁决）

后续推进项目时，默认链路统一为：

**意图 → review plan → 回写 → optimize prompt → spawn**

其中：
- **意图**：明确任务目标、边界与成功标准；
- **review plan**：先评审计划质量（可行性、风险、依赖、验收点）；
- **回写**：将评审后的关键结论沉淀到任务上下文与相关文档；
- **optimize prompt**：将执行指令精炼为可直接派发的高质量提示；
- **spawn**：再进行执行派发。

### 2) 选择该链路而非“直接裸 spawn”的原因

该链路比直接裸 spawn 更稳，原因如下：

1. **先收敛再执行**：在派发前完成目标与边界校准，降低执行偏航概率；
2. **风险前置暴露**：通过 review plan 提前发现依赖、冲突和验收缺口；
3. **上下文可追溯**：回写动作形成稳定证据链，便于交接与复盘；
4. **派发质量更高**：optimize prompt 使执行输入更清晰，减少反复澄清；
5. **协作一致性更强**：多任务并行时仍能保持统一节奏与治理标准。

### 3) 三条例外及处理方式

以下情况允许不走完整默认链路，但必须按对应方式处理：

1. **极小任务**（低风险、低耦合、可快速完成）
   - 处理：可简化为“意图确认后直接执行”，但需最小化回写（至少记录目标与结果）。

2. **纯同步确认**（仅需口头/即时确认，不涉及实际派发执行）
   - 处理：可止于“意图 + 结论”，不强制 spawn；若后续转执行，需补齐回写并进入 optimize prompt。

3. **紧急止血**（线上故障/高优先级风险需即时处置）
   - 处理：允许先执行止血动作，后补 review plan 与回写；补录应覆盖决策依据、风险与后续修复计划。

### 4) 非目标（明确不做）

本 ADR 不包含以下目标：

1. **不追求全自动化**：该链路用于提升治理稳定性，不等于端到端无人化；
2. **不替代判断**：保留负责人和执行者的专业判断与临场裁量；
3. **不改变执行者**：该 ADR 仅定义推进链路，不变更执行责任归属；
4. **不把 plan 写成执行手册**：计划用于决策与约束，不要求展开为逐步操作说明。

### 5) 与规则层、workflow 的接口约定

- **规则层接口**：本 ADR 作为治理原则来源，被规则文档引用并细化为可检查约束；
- **workflow 接口**：本 ADR 作为流程选择依据，被 workflow 文档引用并映射为可操作阶段。

约定：
- 规则层负责“做事边界与合规约束”；
- workflow 负责“阶段编排与流转顺序”；
- 本 ADR 负责“默认链路与例外政策”的顶层裁决。

### 6) 与已有文件的关系

本 ADR 与已落地文档关系如下：

- 规则层已落：`docs/skillforge-execution-rules-v1.md`
- workflow 已落：`docs/skillforge-execution-workflow-v1.md`

二者应在后续版本中显式引用本 ADR（`ADR-0066`）作为上位决策依据。

## Consequences

采用该决策后，预期结果：

- **正向影响**
  - 默认推进路径统一，跨任务协作成本下降；
  - 任务派发前质量门前移，返工率降低；
  - 文档证据链更完整，复盘与审计成本下降。

- **成本与权衡**
  - 相比直接裸 spawn，前置步骤增加，短期启动速度略慢；
  - 需要团队形成“先 review/回写、再派发”的纪律。

- **执行要求**
  - 常态任务遵循默认链路；
  - 命中例外时可走快速路径，但必须按约定补录关键信息；
  - 规则文档与 workflow 文档在迭代时需保持与 ADR-0066 一致。
