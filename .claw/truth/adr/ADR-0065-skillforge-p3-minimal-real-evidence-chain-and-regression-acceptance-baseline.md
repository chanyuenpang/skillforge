# ADR: SkillForge P3 最小真实证据链与回归验收基线

## Status

accepted

## Context

第五阶段已经把主线推进到最小真实执行闭环与产品主线，P1 也已经把最小真实对象链与状态机主干收束成统一锚点。但如果只停留在对象链定义，后续实现仍可能继续把“有对象”误当成“有真实证据、有真实验收”。

因此，P3 需要进一步把第五阶段真正可用的验收门槛收成最小证据链与最小回归验收基线：明确哪些证据位必须真实落地，哪些回归项构成最小通过面，以及哪些结论必须附带覆盖边界与未覆盖边界，避免用空数据闭环或代码存在性替代验收。

## Decision

决定将 SkillForge 第五阶段 P3 的负责人级交付固定为“最小真实证据链与回归验收基线”，并按以下规则推进：

1. 最小真实证据链必须明确固定 `ExecutionRun` / `Evidence` / `Transcript` / `Log` / `Retro` 的最小证据位，且每个关键节点都要知道要存什么、由谁存、如何回看。
2. 最小回归验收必须以真实样本、真实回归、真实验收为边界，不能用空数据闭环、接口存在、代码存在或文档存在替代验收。
3. 结论输出必须同时说明覆盖范围与未覆盖范围，避免把局部样本验证外推成全量可运营结论。
4. 覆盖范围模板、继续冻结项与后续接口约束必须显式固化，作为后续 P4、P5 与实现层真实样本验收的共同门槛。
5. 该阶段沉淀的不是扩展测试体系，而是能直接约束后续实现/验证的验收锚点文档。

## Alternatives Considered

- 继续扩展治理收口或对象链定义：被拒绝，因为这些上位规则已经在前序阶段收束完毕。
- 直接转入规模化真实样本或长周期稳定性结论：被拒绝，因为当前仍需要最小真实证据链先成立。
- 只记录一次性验证结果，不沉淀覆盖边界模板：被拒绝，因为这样会让后续验收结论失去边界约束。

## Consequences

- 正向：第五阶段的验收从“有对象链”进一步收紧到“有真实证据与真实回归”。
- 正向：后续实现不容易再用空数据闭环或代码存在性冒充验收通过。
- 正向：覆盖范围与未覆盖范围被明确分开，局部样本不再自动外推。
- 取舍：本阶段不追求更大规模的稳定性结论，推进节奏会更克制。
- 风险：如果后续忽略边界模板，验收结论会再次失真。
