# SkillForge B8 第二阶段负责人收口口径（v1）

## 第一段：范围声明
本口径只覆盖第二阶段负责人收口归并，不包含阶段退出判定，也不包含第三阶段准入裁决。

## 第二段：可签收项
### 1. 文档治理与收口口径统一
- 状态：`已实现`
- 证据：B5 / B6 / B7 收口文档、roadmap
- 覆盖范围：治理层与表达层一致性
- 未覆盖范围：不等于实现交付或规模化验证完成

### 2. 事实回写框架可复用
- 状态：`已实现`
- 证据：B7 回写映射文档、truth 承载位
- 覆盖范围：事实沉淀框架
- 未覆盖范围：不等于自动事实回写

### 3. M6 范围内最小验证成立
- 状态：`已验证`
- 证据：M6 联调验证记录、第二阶段增强真相、阶段状态总表
- 覆盖范围：最小样本 / 命令样例层
- 未覆盖范围：不等于大规模真实业务样本充分验证

### 4. 治理守门前提已明确
- 状态：`已实现`
- 证据：B7 收口文档、状态总表、增强真相
- 覆盖范围：先回归再扩展的守门逻辑
- 未覆盖范围：不等于退出判定完成

### 5. roadmap 红线已落地到收口表达
- 状态：`已实现`
- 证据：roadmap、B5 / B6 / B7 收口文档
- 覆盖范围：反夸大表达规范
- 未覆盖范围：不等于高阶能力已验证

## 第三段：保留项 / 待补证据项
- 大规模真实业务样本、长周期稳定性与复杂工况证据
- 复杂异常路径与失败恢复链路验证
- 自动联调、自动修复 / 回滚 / 优化、智能推荐 / 分析
- 跨任务 / 跨项目深联动、治理图谱、Skeleton 高阶评分与推荐联动
- 第二阶段正式退出结论、第三阶段入口成立结论

## 第四段：争议降级规则
- 第二阶段已完成 / 已退出 → 收口材料与事实归并已完成到可判定状态，退出结论待主计划守门
- 第三阶段入口已成立 → 已具备入口判断依据 / 候选条件，是否成立待负责人裁决
- 已可运营 / 全面上线 / 全量验证通过 → 在已覆盖样本与链路范围内通过验证
- B6 / B7 / B8 能力已交付 → 规则层与文档层收敛已完成，实现层与规模化验证仍在后续范围
- 自动化能力已具备 → 当前仅形成治理定义或候选方向，未形成可签收实现证据

## 第五段：禁用与降调词典
### 禁用
- 第二阶段正式结束 / 正式退出
- 第三阶段已进入 / 入口已确认
- 全面可运营 / 全链路已验证 / 全量 happy path 完成
- 自动修复 / 自动回滚 / 自动推荐已上线

### 降调
- 已完成 → 在文档治理层 / 最小样本范围内已实现并有证据
- 已验证 → 仅限已记录样本与链路
- 可复用 → 规则与模板可复用，实现效果待规模验证
- 可推广 → 具备继续推进条件，推广需补证据

## 第六段：负责人可签收边界句
可签收的是治理与最小验证事实；不可签收的是阶段退出结论与下一阶段成立结论。
