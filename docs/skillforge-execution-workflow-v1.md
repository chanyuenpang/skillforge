# SkillForge 执行工作流（v1）

> 本文仅定义执行路径与流程衔接，不重定义任何判定规则、阈值或操作细则。所有判定点均**引用规则层**：`docs/skillforge-execution-rules-v1.md`。

## 0. 文档边界说明

- 本 workflow 只描述“先做什么、后做什么、失败后怎么回流”。
- 任何条件判断（是否进入下一步、是否例外放行、是否可重试、是否允许 spawn、何时收口）均**依规则层裁决**。
- 本文不展开：
  - 判定标准定义
  - 阈值解释
  - 规则条款重写
  - 操作手册式步骤细节

---

## 1. 主路径（标准执行链）

路径：**意图 → review plan → 回写 → optimize prompt → spawn**

### 1.1 意图
- 输入任务需求，形成可执行意图描述。
- 是否满足进入 review plan 的条件：**依规则层裁决**。

### 1.2 review plan
- 对意图进行方案审阅与可执行性检查。
- 审阅通过/驳回/补充要求的判定：**引用规则层**。
- 若不通过，回流到意图补全或进入失败检测（是否直接视为失败由规则层裁决）。

### 1.3 回写
- 将审阅结果回写到任务上下文（包括必要的结构化结论）。
- 回写完整性与可追溯性校验：**依规则层裁决**。
- 回写失败则进入失败检测路径。

### 1.4 optimize prompt
- 基于回写结果进行 prompt 优化与收敛。
- 优化是否达标、是否需迭代优化：**引用规则层**。
- 未达标则按规则层要求回流（可回到 review plan 或回写节点）。

### 1.5 spawn
- 发起执行子任务（或执行单元）创建。
- spawn 前置校验（含参数、上下文、边界一致性）与放行条件：**依规则层裁决**。
- spawn 后进入结果回流收口（收口条件与终止判定：**引用规则层**）。

---

## 2. 例外路径 A：极小任务

适用场景识别：是否属于“极小任务”由**规则层裁决**。

建议路径：
- 意图 →（轻量 review plan）→ 回写 →（可选 optimize prompt）→ spawn/直执

说明：
- 是否允许跳过部分节点、跳过范围、最小校验集：**引用规则层**。
- 直执或最简 spawn 的准入与风险边界：**依规则层裁决**。
- 完成后仍需回流收口，收口标准：**引用规则层**。

---

## 3. 例外路径 B：紧急止血

触发识别：是否构成“紧急止血”由**规则层裁决**。

建议路径：
- 意图（止血目标优先）→ 快速 review plan → 快速回写 → 受控 spawn（或临时执行）→ 事后补齐

说明：
- 紧急通道下可压缩环节、可延后事项、必须保留的最小安全检查：**依规则层裁决**。
- 止血动作完成后的补录、复盘、回归主路径时点：**引用规则层**。
- 若紧急动作失败，转入失败重试路径，是否允许连续止血重试：**依规则层裁决**。

---

## 4. 失败重试路径

路径：**失败检测 → 原因归类 → 重试条件判断 → 重试执行 → 失败兜底**

### 4.1 失败检测
- 在任一节点（review plan / 回写 / optimize prompt / spawn / 回流收口）检测失败信号。
- 失败信号定义与触发阈值：**引用规则层**。

### 4.2 原因归类
- 对失败进行类型归类（输入问题、流程问题、执行问题、外部依赖问题等）。
- 归类口径与优先级：**依规则层裁决**。

### 4.3 重试条件判断
- 判断是否满足重试、是否允许换路径重试、是否需升级处理。
- 条件门槛、次数上限、冷却策略：**引用规则层**。

### 4.4 重试执行
- 按归类结果选择对应回流节点执行重试（如回到意图、review plan、回写或 optimize prompt）。
- 重试前校验与重试后复核：**依规则层裁决**。

### 4.5 失败兜底
- 当不满足重试条件或重试耗尽时，进入兜底处置。
- 兜底动作、升级路径、终止与交接标准：**引用规则层**。

---

## 5. 回流与收口（跨路径共用）

- 主路径、例外路径、重试路径最终均需进入统一收口。
- 收口包含：状态闭环、结果落账、后续动作指派（若有）。
- 收口完成判定、未收口处理与二次回流：**依规则层裁决**。
