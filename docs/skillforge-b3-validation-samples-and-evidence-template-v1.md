# SkillForge B3 原型验证样例与证据模板（v1）

## 5.1 验证目标与范围声明
本文只覆盖 B3 Skeleton 原型的“可创建 / 可应用 / 可追溯”最小验证，不外推为评分、推荐、自动优化或全量 happy path 验证完成。

## 5.2 口径与判定标准
### 已实现
字段、状态机、映射规则、检查规则存在，界面可显示相关字段。

### 已验证
存在真实样例证据，且至少覆盖：
- 一个正向链路
- 一个负向阻断
- 一个追溯回看

### 未验证
只有文档定义、分支代码、空数据演示或单点截图，无链路证据。

## 5.3 最小样本矩阵
### 场景A：Draft → Ready 后被新建 StepPlan 应用
- 证明“可创建 + 可应用”最小闭环

### 场景B：Apply 后人工 Adjust，再 Lock / Submit
- 证明“可应用但仍受约束”

### 场景C：PromptDraft 关键字段变更触发待同步确认
- 证明三方一致性门禁真实生效

### 场景D：版本锁定后回看 Approval / Run 来源
- 证明“可追溯”成立

### 场景E：非法引用与状态错误的负向样本
- 证明守门规则真实阻断

## 5.4 单样例证据模板
- `caseId`
- `caseName`
- 验证日期
- 验证人
- 环境标识
- 验证层级（对象层 / 门禁层 / 回看层）
- 状态口径（已实现 / 已验证 / 未验证）
- `taskRef`
- `promptDraftRef(version)`
- `skeletonRef(skeletonId, skeletonVersion)`
- Skeleton Apply 时状态
- `StepPlan(id, version, status, owner, updatedAt)`
- 映射是否生成
- 三方冲突检查结论
- 关键检查点语义是否保留
- Apply 检查结论
- Lock / Submit 结论
- 失败原因码 / 文本
- Approval / Run 回看结果
- 证据附件指针（日志 / 截图 / JSON 片段 / 时间戳）
- 结论：本样例证明了什么 / 未证明什么
