# SkillForge B4 验收口径与非目标声明（v1）

## A. 口径声明
B4 只交付“审批与执行证据链最小守门口径”，不等同于全链路治理平台或规模化运营能力落地。

## B. 验收分界表
### 已实现
- 最小证据链对象模型与主关系口径已定义
- 三段门禁与阻断 / 告警分层规则已定义
- 版本一致性必须一致项已明确
- 回看最小可见槽位与异常槽位已定义
- B4 范围边界已收敛

### 已验证
- B4 one-pager / 对象关系 / 门禁核验 / 回看槽位之间的文档口径对齐可被审阅验证
- `已实现 / 已验证 / 未验证` 状态口径可执行性已验证
- 若存在具体样例，可验证最小主路径可被人工回看串起

### 未验证
- 真实业务样本下的全链路稳定性与覆盖率
- 复杂审批策略、自动血缘、智能影响分析、质量评分、智能推荐、自动编排
- 跨任务 / 跨域深追溯图谱与规模化治理看板
- 执行复盘自动反哺 Skeleton 的闭环成效

## C. 最小验收维度清单
- 范围与边界
- 对象完备
- 关系可追溯
- 版本一致性
- 门禁有效性
- 锁定与修订
- 异常可解释
- 状态口径

## D. 非目标与越界排除
- 不承诺全链路治理平台或规模化运营能力
- 不纳入复杂审批策略引擎
- 不纳入自动化血缘、智能影响分析、质量评分、智能推荐、自动优化 / 自动编排
- 不纳入跨任务 / 跨域深追溯图谱与高级治理看板
- 不给接口、权限、策略引擎细则背书
- 不将执行复盘自动反哺 Skeleton 作为 B4 交付项

## E. 禁用表述黑名单
- B4 已完成审批执行全链路治理 / 全面落地
- 版本追溯能力已全面验证
- Skeleton 闭环已完整落地（含评分 / 推荐）
- 运行中心已具备规模化治理能力
- 代码已实现 = 功能已验证
- 规则已定义 = 线上可审计可回放
- 空数据闭环 = 真实样本闭环
- 单条 happy path 抽测 = 全量场景验证完成

## F. 发布前自检
- 是否出现定义替代验证
- 是否出现代码替代证据
- 是否遗漏未验证范围
- 是否出现跨阶段承诺

## G. 对外发布模板
只报告“当前成立范围 + 未验证边界 + 下一步待证事项”。
