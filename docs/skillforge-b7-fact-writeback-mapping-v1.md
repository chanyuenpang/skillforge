# SkillForge B7 事实层回写承载位与字段模板说明（v1）

## A. 目的与边界
本文只定义 B7 第二阶段事实层回写的承载位与字段基线，不新增能力承诺。

## B. 承载位映射总表
### 1. `.claw/truth/skillforge-阶段状态总表.md`
- 用途：阶段级总览真相入口
- 写入内容：M6 → B7 的阶段状态、结论、待收口项、下一阶段入口前提

### 2. `.claw/truth/skillforge-M6-联调验证记录.md`
- 用途：联调与回归动作级证据记录位
- 写入内容：验证动作、证据锚点、覆盖 / 未覆盖、阻塞 / 风险

### 3. `.claw/truth/skillforge-第二阶段增强真相.md`
- 用途：增强结论归拢位
- 写入内容：能力条目、状态、关键事实、证据锚点、覆盖边界、守门要求

### 4. `docs/` 下 B7 口径文档
- 用途：规范口径位
- 写入内容：规则、模板、禁用表达、判定标准

### 5. phase 报告承载位
- 用途：阶段推进与偏差位
- 写入内容：本轮目标与实际达成、偏差、风险、回写清单

## C. 字段模板
### 阶段状态总表（truth）
- 阶段标识
- 当前状态
- 已有结论
- 当前待收口项
- 下一阶段入口前提

### 联调验证记录（truth）
- 记录单元标识
- 结论状态：`已实现 / 已验证 / 未验证`
- 验证动作
- 证据锚点
- 覆盖范围
- 未覆盖范围
- 阻塞 / 风险

### 第二阶段增强真相（truth）
- 能力条目
- 状态
- 关键事实
- 证据锚点
- 覆盖边界 / 限定语
- 守门要求

### phase 报告
- 本阶段目标与实际达成
- 偏差与原因
- 风险与后续动作
- 对 truth / roadmap / doc 的回写清单

## D. 分工边界
- truth：写可验证的阶段事实、状态变化、验证记录、证据锚点、覆盖与未覆盖
- phase：写推进过程、偏差、风险、优先级调整、回写动作追踪
- 主文档：写长期治理规则、阶段边界、非目标、术语与判定模板

## E. 首批纳入清单与排除清单
### 第一批纳入
- 三分状态口径
- 结论四元组：事实 / 动作 + 证据锚点 + 覆盖范围 + 未覆盖范围
- 主链一致性核验结果
- 门禁语义结果
- 阻断 / 告警分层记录
- 证据不足降级为 `未验证 / 后续候选`

### 暂不纳入
- 自动事实回写、自动修复、自动回滚
- 跨项目 / 跨任务深联调图谱
- 智能血缘推断、自动影响分析、评分推荐
- 运营级复杂看板与策略引擎
- 将 B8 / 阶段 C-D 能力前置写入 B7 结论

## F. 口径守门附录
- 禁用表述
- 降级规则
- 结论句式示例（含范围限定词）
