# SkillForge B8 边界冻结与禁用表述复核说明（v1）

## A. 复核范围声明
本文只复核 B8 收口边界与话术合规，不作第二阶段退出裁决，也不作第三阶段准入裁决。

## B. 可签收事实清单呈现规则
每条事实统一按四元组呈现：
- 状态
- 证据锚点
- 覆盖范围
- 未覆盖范围

## C. 边界冻结条款
- 禁止把收口事实写成阶段退出结论
- 禁止把最小样本验证写成全量可运营
- 禁止把文档治理收敛写成实现交付完成
- 禁止把代码 / 分支已实现写成能力已验证
- 禁止把入口判断依据写成入口已批准

## D. 禁用与降调词典
### 禁用
- 第二阶段正式结束 / 正式退出（已确认）
- 第三阶段已进入 / 入口已确认 / 已获批准执行
- 全面可运营 / 全链路已验证 / 全量 happy path 完成
- 自动修复 / 自动回滚 / 自动推荐已上线（可签收）
- B8 已完成全部交付，可直接规模化推广
- 代码已实现 = 能力已验证

### 降调
- 已完成 → 在文档治理层或最小样本范围内已实现并有证据
- 已验证 → 仅限已记录样本与链路范围
- 可复用 → 规则 / 模板可复用，实现效果待规模验证
- 可推广 → 具备继续推进条件，推广需补证据
- 可进入下一阶段 → 具备入口判断依据，是否进入待负责人裁决

## E. 回退触发条件
以下情况必须回退为 `未验证 / 候选 / 条件化`：
- 证据锚点不可追溯
- 覆盖范围与结论不匹配
- 文档间口径冲突
- 基线守门缺失
- 未覆盖风险被省略
- 越权结论

## F. 最后一轮负责人自检清单
- 边界句是否守住
- 四元组是否完整
- 禁词是否残留
- 是否存在外推
- 是否写明基线回归先行、补证后判定
- 未验证池是否完整保留
- 裁决位是否保留

## G. 合规收口句模板
已具备入口判断依据（限已覆盖范围），是否进入由负责人裁决。
