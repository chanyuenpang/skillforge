# SkillForge D0 条件化启动边界与补证闸门（v1）

## 1. D0 文档目标与适用边界
本文只定义第四阶段条件化启动边界，不构成阶段切换结论。

## 2. 输入依据与证据锚点
- `docs/skillforge-owner-decision-page-v1.md`
- `docs/skillforge-b8-sync-and-close-memo-v1.md`
- `docs/skillforge-c5-phase-c-closeout-inputs-v1.md`
- `docs/skillforge-roadmap-and-doc-governance-v1.md`
- `tasks/skillforge-第四阶段主计划/plan.json`

## 3. D0 需锁定的核心问题清单
- 条件推进 ≠ 自动切换
- 入口判断依据 ≠ 高阶能力成立
- 先补证、先回归，再讨论候选能力解锁
- 冲突、证据不足、回归失败时必须回退

## 4. 启动前提（最小集）
- 口径前提：统一使用“条件推进”“入口判断依据（限已覆盖范围）”
- 证据前提：B8 与 C5 四元组事实可追溯
- 治理前提：按进入/退出条件治理
- 回归前提：基线回归先行

## 5. 补证闸门
- 未验证池显式挂牌
- 补证优先顺序明确
- 证据类型必须有效，不能用代码存在/空数据闭环/单次样本替代已验证
- 每条结论必须配覆盖范围与未覆盖范围

## 6. 回退条件与降级处理口径
- 回归失败或与既有基线冲突 → 回退
- 新补证无法闭合关键风险 → 回退
- 口径越界（把候选写成默认解锁）→ 回退
- 文档证据链断裂 → 回退

## 7. 冻结边界清单
- 阶段状态边界：第四阶段是条件化启动，不是默认进入
- 能力承诺边界：自动化、规模化、跨项目治理继续冻结
- 验证外推边界：最小验证不得外推为全量可运营
- 文档语义边界：D0 不承载执行方案

## 8. 禁用 / 降调词典（D0版）
### 禁用
- 已进入第四阶段 / 已批准切换 / 自动切换完成
- 全面可运营 / 全链路已验证 / 全量验证完成
- 自动化能力已落地
- 规模化能力已成立 / 跨项目治理已成熟

### 降调
- 可以进入下一阶段 → 已具备入口判断依据（限已覆盖范围），是否进入待负责人裁决
- 阶段 C 已完成 / 已退出 → 阶段 C 收口输入已具备负责人裁决基础
- 回沉闭环已自动运行 → 回沉治理路径已定义，自动化未纳入承诺
- 文档联动已自动化 → 已形成可人工执行的触发与回写基线
- 能力已成立 → 能力候选已定义，待补证与回归后再判定

## 9. D0 通过 / 不通过判据
- 通过：条件边界成文且可追溯
- 不通过：出现自动解锁叙事或证据断链

## 10. 与 D1-D5 的接口说明
D0 输出的启动边界、补证闸门、回退口径与冻结边界，作为 D1-D5 的统一前置条件。
