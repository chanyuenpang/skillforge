## III. 未验证池拆分结果
### A. 自动化执行类（高风险能力池）
- 自动回写
- 自动优化
- 自动根因诊断
- 自动修复 / 回滚
- 自动一致性修复
- 自动推荐联动

### B. 规模化治理类（外推能力池）
- 大规模真实业务样本充分性
- 复杂血缘图谱
- 深度影响分析
- 跨项目规模化知识回流
- 复杂联动看板

### C. 稳定性与异常韧性类（可靠性池）
- 复杂异常场景
- 长期稳定性
- 恢复能力验证不足

### D. 策略化优化类（阶段 D 候选池）
- 编排策略数据驱动优化
- Skeleton 质量评分体系

## IV. 优先级重排矩阵
### 先补证
- C 类：稳定性与异常韧性

### 条件化补证
- A 类中只读 / 建议型、不触发自动执行的子项观察证据

### 继续挂账
- B 类：规模化治理

### 远期候选
- D 类：策略化优化

### 排序依据
- 是否影响基线回归先行
- 是否影响冲突即回退可执行性
- 是否会造成承诺越界
- 证据是否满足四元组
- 是否依赖当前未具备的大样本或跨项目条件

## V. 冻结清单
- 自动化执行闭环类继续冻结
- 规模化 / 跨项目成熟度类继续冻结
- 禁止“已实现即已验证”“单次样本即全量可运营”叙事

## VI. 口径统一规范
- 未验证 = 尚无充分证据闭环
- 候选 = 路线方向存在，但不构成当前承诺
- 条件化前提 = 可进入评估 / 准备的入口条件，不等于能力成立
- 候选 ≠ 默认后续任务
- 入口判断依据 ≠ 阶段自动切换
- 已实现 ≠ 已验证 ≠ 可规模化运营
- 每条结论必须带：证据锚点 / 覆盖范围 / 未覆盖范围 / 回退触发

## VII. 与 D2-D4 的接口说明
D1 的拆分结果与优先级矩阵，作为 D2 补证链路设计、D3 候选能力解锁条件定义、D4 执行主线准备的共同输入。
