# SkillForge B5 验收口径与防越界检查（v1）

## A. 验收口径总述
B5 只定义知识与资产管理标准化的规则层验收，不代表智能推荐、自动优化或后续阶段能力已经完成。

## B. 三分状态总表
### 已实现
- B5 规则层文档与口径基线已形成
- `Skeleton@version` 对象规范、`stages[]` 约束与生命周期状态已定义
- Apply → Adjust → Lock → Trace 最小动作链已定义
- `skeletonRef(id+version)`、`StepPlan@v -> PromptDraft@v`、锁定后不可无痕改写等关键语义已定义

### 已验证
- B5 one-pager、对象边界、元数据基线、跨域校核、复用追溯与 roadmap 治理规则在文档表述上相互对齐
- 口径守门已验证：明确禁止“已实现=已验证”“代码存在=全量验证”“空数据闭环=业务全量验证”

### 未验证
- Skeleton 库全链路产品化验证与跨任务规模化复用效果
- 自动推荐、自动优化、自动一致性修复、自动反哺 Skeleton
- 跨项目复杂治理图谱、深血缘推断、复杂审批分层与智能影响分析

## C. 最小验收维度清单
- 范围守门
- 对象与边界
- 元数据与版本
- 引用与锁定
- 一致性校核
- 追溯可回看
- 状态与证据
- 越界表述治理

## D. 防越界清单
- 不承诺智能推荐、质量评分、推荐排序、自动分类 / 标签
- 不承诺自动优化、自动一致性修复、自动反哺 Skeleton
- 不承诺跨任务 / 跨项目复杂治理图谱与运营级联动看板
- 不承诺复杂审批分层与智能影响分析
- 不把 Approval / Run 并入资产对象层
- 不把 B6 / B7 / B8 能力前置到 B5

## E. 禁用表述清单
- B5 完成后即具备智能推荐 / 自动优化能力
- Skeleton 库已全链路产品化验证完成
- 已支持自动从执行复盘反哺并改写 Skeleton
- 运行中心 / 知识资产已经全面可运营
- 代码实现 = 能力可交付
- 已实现 = 已验证
- 空数据闭环 = 有业务样本的全面验证
- 分支代码已实现 = happy path 已实测完成

## F. 结论模板
- 已实现：实现事实 + 证据锚点 + 未覆盖范围
- 已验证：验证动作 / 样本 + 证据锚点 + 覆盖边界
- 未验证：缺口说明 + 风险提示 + 后续阶段归属

## G. 回退机制
出现争议或证据不足时，统一降级为 `未验证 / 后续阶段候选`。
