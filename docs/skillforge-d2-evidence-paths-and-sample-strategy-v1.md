## 5.3 高价值补证链路清单
### 链路A：基线回归与回退可执行性
- 价值：证明条件推进可信
- 证据最小集：回归先行 / 冲突触发 / 回退执行 / 口径降级
- 边界：不把“有规则”写成“规则已验证可执行”

### 链路B：执行—复盘—回沉人工治理闭环
- 价值：补强 C3 主干闭环
- 证据最小集：Run → Retro → Skeleton 修订提议可追溯
- 边界：不外推为自动回写 / 自动诊断成立

### 链路C：文档联动与回写冲突场景
- 价值：补强 truth / phase / spec / ADR 一致性
- 证据最小集：触发矩阵稳定、冲突优先级与回退路径可复现
- 边界：不写成文档联动自动化

### 链路D：资产复用链路有效性
- 价值：验证 Apply → Adjust → Lock → Trace 是否防漂移
- 证据最小集：版本追溯一致性、Lock 与 Trace 生效
- 边界：不外推为规模化复用成熟

### 链路E：未验证池口径守门链路
- 价值：防止候选能力越界成默认能力
- 证据最小集：候选 / 未验证 / 条件化前提持续区分

## 5.4 验证样本分层基线
### L1 基线守门样本
- 证明条件推进机制有效

### L2 主链路闭环样本
- 证明 C2 / C3 / C4 既有承诺范围内链路可重复

### L3 异常与边界样本
- 证明失败路径、冲突路径、证据断链路径能回退

### L4 观察性候选样本
- 仅为未来冻结能力积累观察证据，不进入当前承诺

## 5.5 样本与证据准入规则
### 可纳入
- 带四元组的链路样本
- 含异常分支的回退样本
- 文档联动样本
- 有限多次样本中的一致性记录

### 不可冒充
- 代码存在性 / 分支实现状态
- 空数据闭环 / 单次命令 / 单 happy path 抽测
- 无未覆盖范围声明的完成结论
- 候选能力观察记录被包装成已落地
- 局部样本外推为全链路已验证 / 全面可运营 / 规模化成熟

## 5.6 统一口径与禁词降调对照
- 条件推进 = 启动准备动作，不等于阶段状态变更
- 入口判断依据成立 ≠ 已进入下一阶段
- 已实现 ≠ 已验证 ≠ 可规模化运营
- 候选能力 = 方向存在，不构成当前承诺
- 未验证 = 证据闭环不足
- 每条结论必须带：证据锚点 / 覆盖范围 / 未覆盖范围 / 回退触发
