# SkillForge B6 验收口径与防越界检查（v1）

## 0. 文档定位与边界声明
本文只定义 B6“配置与系统能力受控发布入口”的验收口径与防越界检查，不是实现方案或交付宣言。

## 1. 结论总览（三分法）
### 已实现
- B6 规则层与口径层已形成：范围、三段门禁、最小对象链、版本一致性核验、可见性与异常槽位、三分法结论模板。
- B6 边界与非目标已明确：不扩展到复杂策略引擎、自动修复、自动回滚、智能分析。
- 与 B4 / B5 / roadmap 的治理锚点关系已明确。

### 已验证
- 文档层一致性已验证：B6 one-pager、对象与状态流、门禁映射、可见性槽位之间无明显冲突。
- 口径守门规则已验证：禁止“已实现 = 已验证”“代码存在 = 交付完成”“空数据闭环 = 业务全量验证”。

### 未验证
- 真实业务样本下的提交 → 审批 → 生效 → 回看全链路验收覆盖充分性。
- 异常场景在真实数据与多案例下的稳定性。
- 跨任务 / 跨项目治理、自动诊断与修复、智能推荐等能力。
- Skeleton 高阶联动与运营级看板能力。

## 2. 最小验收维度与通过判据
- 范围守门
- 对象链完整性
- 三段门禁有效性
- 版本一致性
- 状态与锁定语义
- 可见性与异常解释
- 证据三分法
- 争议回退机制

## 3. 防越界清单
- 不做智能推荐、自动优化、自动编排、自动回滚、自动一致性修复、自动根因分析
- 不做复杂审批策略状态树、跨任务 / 跨项目复杂治理图谱、运营级高级看板
- 不做 Skeleton 质量评分、场景推荐、自动反哺联动
- 不前置宣称 B7 / B8 / 阶段 C-D 能力已在 B6 完成
- 不把分支实现 / 空数据闭环 / 单样本上升为全面可运营验证

## 4. 禁用表述清单
- B6 完成后已具备智能推荐 / 自动优化能力
- 配置与系统能力已全面可运营、可规模化治理
- 代码实现完成 = 能力交付完成
- 已实现 = 已验证
- 空数据闭环 = 业务样本全量验证完成
- 分支代码已实现 = happy path 实测完成
- B6 已完成全链路全场景验证
- 异常已可自动定位根因并自动修复

## 5. 证据挂载与回退规则
- 每条结论统一格式：事实 / 动作 + 证据锚点 + 覆盖范围 + 未覆盖范围
- 证据不足或口径冲突时，统一降级为 `未验证 / 后续候选`

## 6. 与 B5、roadmap 的对齐附注
B6 只是在 B5 守门基础上的入口治理延伸，不改变第二阶段边界。
