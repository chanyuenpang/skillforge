## 3. 执行主线总述
- 先证明条件推进机制本身可靠
- 再在已覆盖范围内推进补证与联动
- 候选能力只保留在条件评估 / 观察语义，不进入已成立承诺

## 4. 准备动作最小顺序与前置条件
1. 先锁口径与闸门
2. 先做基线回归与回退可执行性补证
3. 再做主链路补证
4. 最后仅把候选能力放入条件评估区

## 5. 文档联动触发矩阵
### 必须触发文档联动
- 边界口径变化、禁词降调、回退触发条件变化
- 补证结论落地
- 文档联动冲突处理结果
- 对象关系或映射规则变化

### 仅条件化准备动作
- 自动回写 / 自动优化 / 自动诊断 / 自动修复 / 自动回滚 / 自动一致性修复 / 自动推荐联动
- 规模化治理项
- 策略化高阶项

## 6. 口径统一与禁词降调复核区
- 条件推进 ≠ 阶段自动切换
- 入口判断依据成立 ≠ 已进入下一阶段
- 已实现 ≠ 已验证 ≠ 可规模化运营
- 可进入条件评估区 ≠ 已解锁
- 候选能力 ≠ 默认后续执行任务

## 7. 冻结清单与条件评估清单
- 冻结：自动化闭环执行能力、规模化治理能力、策略化高阶能力
- 条件评估：稳定性与异常韧性、只读/建议型子能力、人工治理强化能力

## 8. D4 产出验收口径
只验主线稳定与可追溯，不验高阶能力已启动。
