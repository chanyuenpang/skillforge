# SkillForge B1 第一批动作面盘点（v1）

## 1. 盘点范围与口径前置
本盘点仅覆盖 B1：运行中心从只读闭环走向基础可操作工作台的第一批动作面，不扩展到 B2/B3 的深编排、Skeleton 深能力与自动化能力。

状态口径仍遵循：已实现 / 已验证 / 未验证 三分法。

## 2. 当前已有承接位
### 2.1 路由与页面承接位
- `/run-center`
- `/run-center/runs`
- `/run-center/runs/:runId`

### 2.2 产品壳层承接位
- 运行中心、审批与风控、总览工作台已在统一壳层共存，可做跨模块跳转承接。

### 2.3 对象口径承接位
- PromptDraft、StepPlan 的对象字段、状态、关系、门禁顺序（`PromptDraft → StepPlan → Approval → Run`）已在领域文档定义，可作为动作命名与状态显示口径承接位。

### 2.4 API 承接位
- `/api/run-center/*` 已接入，当前更适合承接读取型、回看型、轻动作型第一批动作。

## 3. 第一批可直接落位动作清单
### 3.1 运行详情 ` /run-center/runs/:runId `
- 查看执行状态、阶段信息、证据 / 日志回看
- 查看关联审批结果与审批轨迹入口
- 查看关联任务与计划版本标识

### 3.2 执行记录列表 ` /run-center/runs `
- 按状态筛选 / 检索运行记录
- drill-down 进入运行详情

### 3.3 任务详情侧轻动作（若当前已有容器）
- 展示 PromptDraft / StepPlan 当前版本与状态
- 展示提交审批前置条件的只读检查结果
- 发起“进入审批”或“查看审批单”入口（复用既有审批链路）

### 3.4 跨模块通道型动作
- 从运行中心跳转审批与风控处理节点
- 审批完成后回到运行中心查看状态回流

## 4. 需补承载位动作清单
### 4.1 PromptDraft
- 目标 / 约束 / 验收标准等结构化编辑承载位
- 版本修订与差异对比承载位

### 4.2 StepPlan
- 步骤增删改、顺序调整、依赖关系维护
- step 级 inputs / outputs / checks / riskNotes 承载位

### 4.3 提交审批包
- PromptDraft + StepPlan 的提交前确认页 / 锁定页
- LockedForApproval 后的只读锁定与变更阻断提示

### 4.4 状态机落地
- `Draft / Ready / Locked / Approved / Executed / Superseded` 可视化流转控件与规则提示
- “关键字段变更后 StepPlan 待同步确认”提示与处理入口

## 5. 第一批暂缓动作清单
- 自动 prompt 生成
- 自动步骤拆解
- 自动策略优化
- 复杂可视化编排器
- 批量编排
- 跨任务智能推荐
- Skeleton 评分推荐与深度效果反馈自动闭环

## 6. 结论
当前运行中心已经具备“列表 / 详情 / 审批跳转 / 回看”的第一批承接位，适合先做查看态与轻动作型工作台能力。

真正的深编辑、组合提交包、状态机可视化仍需补承载位，不能在 B1 初期直接当作现成能力写入。
