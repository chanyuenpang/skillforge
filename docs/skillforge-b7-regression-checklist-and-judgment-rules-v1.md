# SkillForge B7 回归检查清单与判定口径说明（v1）

## A. 文档定位与边界声明
本文只用于第二阶段回归基线，不构成新增承诺。

## B. 回归对象与最小范围
- B1/B2：运行中心与编排路径
- B3：Skeleton 原型边界
- B5：资产验收口径
- B6：配置入口守门
- 不纳入：智能化、自动化、跨项目深联动、B8 / 阶段 C-D 前置能力

## C. 最少回归检查清单
### 阻断项
- 主链对象可串联：`Task -> PromptDraft@v -> StepPlan@v -> Approval -> Run`
- 覆盖 B3/B5 时补查：`StepPlan@v -> skeletonRef(id+version)`
- 关键引用必须 `@version`
- `Approval.approvedPackageRef` 与 `Run.consumed*Ref@v` 一致
- 门禁链有效：提交 → 审批 → 生效 → 回看
- `Ready` 准入、`LockedForApproval` 后禁止无痕改写
- 结论采用三分法，并带证据锚点、覆盖范围、未覆盖范围

### 告警项
- 提交前检查摘要完整度
- 非关键字段漂移 / 新鲜度风险
- 回看展示质量
- 资产侧最小字段可见性

## D. 判定口径
- 已实现：规则、对象链、门禁、版本一致性规则、口径模板已落文或已存在承载位
- 已验证：必须有真实验证动作、证据锚点、覆盖边界
- 未验证：证据不足、仅空数据、仅分支、仅文档定义，或仍属后续阶段能力
- 冲突或证据不足时，统一降级为 `未验证 / 后续候选`

## E. 证据挂载规范
每条结论统一记录：
- `事实 / 动作`
- `证据锚点`
- `覆盖范围`
- `未覆盖范围`

## F. 未覆盖范围与风险登记
- 主链联调若只覆盖少量样本，必须写未覆盖异常分支与稳定性
- B5 资产相关未覆盖：规模化复用、自动反哺
- B6 入口治理未覆盖：真实业务样本充分性、多案例异常稳定性
- roadmap 高阶目标未覆盖：跨域深联动、策略引擎、评分推荐、规模化看板

## G. 禁用表述与对外话术约束
- B7 已完成第二阶段全部能力交付 / 全面上线 / 全面可运营
- 全链路已完成全场景验证
- 运行中心 / 知识资产已经全面可运营
- 配置与系统能力已可规模化治理
- 已具备跨域深联动、跨项目复杂治理成熟能力
- B7 已覆盖 B8 或阶段 C-D 目标
- 异常已可自动定位根因并自动修复
