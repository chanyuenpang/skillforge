# SkillForge B8 第三阶段入口判定框架（v1）

## A. 适用范围与边界声明
本框架只定义第三阶段入口判定依据，不做第二阶段退出结论，也不做第三阶段准入裁决。

## B. 判定输入清单（最少集）
- 事实底稿一致性输入
- 最小验证完成输入
- 基线守门输入
- 治理红线输入
- 未覆盖风险输入
- 权限边界输入

## C. 判定语义层级与触发条件
### 可进入
- 具备负责人裁决所需的最低依据集
- 仅在已覆盖样本与链路范围内成立

### 有条件进入
- 依据基本具备，但必须绑定前置条件（如先完成基线回归、补齐指定证据）

### 暂不进入
- 存在关键输入缺失或口径冲突，无法形成可信入口判断

### 降级进入
- 仅可做低风险准备动作，不得宣称阶段切换或实质执行启动

## D. 守门前置与补证机制
- 先回归，再扩展
- 证据缺失先补
- 仅条件化处理低风险缺口

## E. 降级 / 暂缓规则
- 文档事实冲突
- 基线守门缺失
- 验证外推过度
- 未覆盖风险被忽略
- 证据锚点不可追溯
- 边界越权

## F. 禁用话术与合规表述词典
### 禁用
- 第二阶段正式结束 / 正式退出（已确认）
- 第三阶段已进入 / 入口已确认 / 已获批准执行
- 全面可运营 / 全链路已验证 / 全量 happy path 完成
- 自动修复 / 自动回滚 / 自动推荐已上线（可签收）
- B8 已完成全部交付，可直接规模化推广
- 代码已实现 = 能力已验证

### 合规表达
- 在已覆盖样本与链路内，具备入口判断依据；是否进入由负责人裁决

## G. 判定记录模板（可追溯）
- 结论
- 证据锚点
- 覆盖范围
- 未覆盖项
- 责任人裁决位

## H. 回写要求
- 判定后同步到 roadmap / truth / phase 的最小回写清单
