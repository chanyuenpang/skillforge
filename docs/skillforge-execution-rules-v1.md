# SkillForge 执行规则集 v1

## 一、Review Plan 规则（3条）

### 规则 1：目标不清必须进入 Review
当任务目标存在多义解释、成功定义不唯一、或上下文无法支撑唯一执行方向时，必须先进入 Review，禁止直接执行。
**完成后必须记录**：触发目标不清的具体表述、统一后的目标定义、以及目标口径确认人。

### 规则 2：边界不明必须进入 Review
当任务的输入边界、输出边界、责任边界任一项不明确，或存在跨角色职责重叠时，必须先进入 Review，禁止在边界未收敛前推进。
**完成后必须确认**：边界清单已完整、边界冲突已消除、边界责任已被指定。

### 规则 3：影响扩散或需拆解委派必须进入 Review
当任务影响多个模块、多个责任域，或需要拆解为可委派单元时，必须先进入 Review 统一影响面和拆解标准，禁止直接派发。
**完成后必须记录**：影响面范围、拆解颗粒度标准、以及委派责任映射。

## 二、Prompt 优化规则（3条）

### 规则 4：指令模糊必须先 Optimize Prompt
当任务指令包含抽象词、主观词、或可被多路径解释的表达，必须先优化 Prompt，形成可执行且可判定的表达后方可执行。
**完成后必须记录**：模糊表达原句、优化后表达、以及可判定条件。

### 规则 5：约束冲突必须先 Optimize Prompt
当任务同时存在相互冲突或优先级未定义的约束时，必须先优化 Prompt，明确约束优先级与冲突处理原则后方可执行。
**完成后必须确认**：冲突约束已显式排序、冲突处理原则已唯一化、执行侧无二义理解。

### 规则 6：缺验收标准或需独立闭环必须先 Optimize Prompt
当任务未给出可验收标准，或要求独立闭环交付（无需外部补充即可验证）时，必须先优化 Prompt，补齐可验证验收口径后再执行。
**完成后必须记录**：验收标准清单、闭环验证条件、以及失败判据。

## 三、跳过规则（3条）

### 规则 7：仅在低不确定性且低外溢风险时允许跳过
仅当任务目标、边界、约束、验收均已明确且影响不外溢时，允许跳过 Review 或 Prompt 优化；任一维度存在不确定性即不得跳过。
**完成后必须记录**：跳过什么、依据是什么、风险怎么控制、后续谁回收修正。

### 规则 8：紧急时效触发跳过必须附带风险封装
因时效压力触发跳过时，必须同步定义风险封装范围、可接受偏差上限、以及最晚回补时点，且不得将未封装风险外溢到非责任域。
**完成后必须确认**：风险封装边界已明确、偏差上限已量化、回补责任人已指定。

### 规则 9：跳过属于例外，必须可追溯与可复盘
任何跳过均视为例外决策，必须具备可追溯证据与复盘入口；无法提供证据链时不得跳过。
**完成后必须记录**：例外决策编号、证据来源、复盘触发条件、以及修正规则的归口责任。

## 四、Spawn 前校验规则 + 结果回流规则（3条）

### 规则 10：Spawn 前必须通过最小校验清单（7项）
发起 Spawn 前必须完成以下最小校验：
1) 目标定义唯一；
2) 输入完整且可用；
3) 输出标准可判定；
4) 约束优先级明确；
5) 验收标准可验证；
6) 风险边界已声明；
7) 责任归属可追溯。
任一项未满足均不得 Spawn。
**完成后必须确认**：七项校验结果逐项为“通过/不通过”且有责任签注。

### 规则 11：结果回流后必须执行收口动作
结果回流后必须完成收口：对齐目标达成度、核对约束一致性、核验验收证据、并归档偏差与处置结论；未收口不得判定任务完成。
**完成后必须记录**：达成度结论、约束核对结论、验收证据索引、偏差处置结论。

### 规则 12：出现偏差必须重定责并闭环修正
当回流结果与目标、约束、验收任一项不一致时，必须立即进行偏差定性、责任重定、修正动作绑定，禁止以口头承诺替代责任闭环。
**完成后必须确认**：偏差等级已定、责任主体已重定、修正时限已锁定、复验责任已明确。
