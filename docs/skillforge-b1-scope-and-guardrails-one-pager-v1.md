# SkillForge B1 范围与口径守门说明（一页版）

## A. B1 目标边界
本阶段仅完成“运行中心基础可操作工作台”的范围收敛与口径一致化：让运行中心从只读闭环走向基础可操作路径，但不外推为高级自动化或跨域深联动已完成。

## B. 本阶段只包含
1. PromptDraft / StepPlan 的基础操作路径定位。
2. 编排 → 审批 → 执行主干的一致性守门。
3. 运行中心内状态、版本、证据的最小可追溯口径。

## C. 本阶段明确不含
- 自动 prompt 生成
- 自动步骤拆解
- 自动策略优化
- 复杂可视化编排器
- 批量编排
- 跨任务智能推荐
- Skeleton 评分与推荐
- 跨域深联动与规模化复用承诺

## D. 状态口径强制规则
### 已实现
代码 / 路由 / API / 页面承载已存在；仅代表“有这个能力构件”，不代表可用性已充分验证。

### 已验证
存在真实样本或真实链路证据通过；可用于对外宣称“该路径已被验证”。

### 未验证
即便已实现，也必须明确标注验证缺口，禁止按已验证叙述。

### 使用规则
- 先写证据层级，再写能力判断。
- 必须区分“第一刀已落位（已实现）”与“当前验证层级（空数据 / 最小样本 / 分支待抽测）”。
- 禁止把已实现、已验证、未验证混写成单一结论。

## E. 禁用表述清单
- B1 已完成运行中心全量工作台能力。
- 编排能力已智能化 / 自动化闭环。
- Skeleton 库已完成全面产品化并验证完毕。
- 空数据闭环 = 业务链路全面验证完成。
- 代码已实现 = happy path 已实测通过。
- 阶段 A 关闭 = 阶段 B 目标已达成。
- 已可规模化复用 / 跨域联动成熟。

## F. 对外描述模板
- 已实现：运行中心基础工作台承载位已建立，相关对象规范已落盘。
- 已验证：当前已验证的是真实空数据闭环与最小样本层级证据。
- 未验证：更深工作台动作链、更多 happy path 与跨域联动仍待后续阶段验证。
- 因此当前仅可宣称：B1 基础工作台路径成立，增强项待后续阶段推进。
