# SkillForge B5 范围与边界守门说明（知识与资产管理标准化）

## A. 目的
本说明只用于冻结 B5 范围与边界，统一知识与资产管理标准化阶段的叙事与验收口径。

## B. B5 仅覆盖范围
- 对齐 roadmap 阶段 B 的治理目标
- 固化 Skeleton 对象 / 状态 / 映射 / 版本引用口径
- 固化证据链最小关系在资产域的表达要求
- 固化 `已实现 / 已验证 / 未验证` 状态三分法与证据锚点写法

## C. 明确不覆盖范围
- 智能推荐、质量评分、自动优化、跨域深联动自动化
- 任何实现细节方案
- 任何 B6 / B7 / B8 的能力承诺

## D. 状态口径规则
- 强制区分：`已实现 / 已验证 / 未验证`
- 每条结论都要带证据锚点与覆盖边界
- 禁止把“定义 / 代码 / 空数据闭环”写成“全量验证完成”
- 涉及 Skeleton 与 StepPlan 关系时，必须带版本语义与 `skeletonRef(id+version)`

## E. 越界词与禁用句
- B5 完成后即具备智能推荐 / 自动优化能力
- Skeleton 库已全链路产品化验证完成
- 已支持自动从执行复盘反哺并改写 Skeleton
- 运行中心 / 知识资产已经全面可运营
- 代码实现 = 能力可交付
- 已实现 = 已验证

## F. 通过条件
- 范围 / 非范围 / 状态口径三块齐全
- 至少引用一组对象与关系锚点（Skeleton、StepPlan、`skeletonRef`、版本）
- 无越界承诺语句

## G. 失败回退
- 回退到“阶段边界 + 证据锚点”重写
- 将争议能力标记为“未验证 / 后续阶段候选”
