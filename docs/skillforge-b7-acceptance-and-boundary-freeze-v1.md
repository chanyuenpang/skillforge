# SkillForge B7 验收口径与边界冻结说明（v1）

## 第1节：定位与适用范围
B7 只做第二阶段联调、回归与事实层回写的口径收口，不新增能力承诺。

## 第2节：状态分界总表
### 已实现
- B7 范围守门、最小联调对象链、门禁链、版本一致性规则、回归清单、事实层回写映射、禁用话术与降级规则已形成。
- B7 与 B5 / B6 / roadmap 的边界对齐规则已形成。
- truth 承载位与字段模板已明确。

### 已验证
- 文档一致性层面：B7 文档与 B5 / B6 / roadmap 的反夸大、三分法、证据锚点、边界限定基本一致。
- 口径守门层面：`已实现 ≠ 已验证`、`代码存在 ≠ 交付完成`、`空数据闭环 ≠ 业务全量验证` 已明确。

### 未验证
- 真实业务样本下的大规模、多异常分支、长期稳定性联调覆盖。
- 自动联调 / 自动修复 / 自动回滚 / 自动优化推荐 / 自动事实回写。
- 跨任务 / 跨项目深联动、复杂治理图谱、智能血缘 / 影响分析、运营级复杂看板与策略引擎。
- 任何 B8 或阶段 C-D 能力前置完成表述。

## 第3节：最少验收维度与通过判据
- 范围与边界守门
- 主链可追溯性
- 门禁链有效性
- 版本一致性
- 状态判定三分法
- 阻断 / 告警分层
- 事实层可回写性
- 争议降级机制

## 第4节：边界冻结与非目标清单
- 不做智能推荐、自动编排、自动修复、自动回滚、自动一致性修复、自动根因分析。
- 不做跨任务 / 跨项目深联调与复杂治理图谱、运营级规模化看板、复杂审批策略引擎。
- 不前置宣称 B8 与阶段 C-D 能力完成。
- 不以分支实现、文档定义、空数据闭环替代真实多样本验证结论。

## 第5节：禁用话术与对外表达模板
### 禁用话术
- B7 已完成第二阶段全部能力交付 / 全面上线 / 全面可运营
- 已实现 = 已验证
- 代码实现 / 分支实现 = 能力交付完成 / happy path 已实测完成
- 空数据闭环 = 业务样本全量验证完成
- B7 已覆盖 B8 或阶段 C-D 目标
- 已具备跨域深联动、跨项目规模化治理成熟能力
- 异常已可自动定位根因并自动修复

### 合规句式
- 已实现：事实 + 证据锚点 + 覆盖边界
- 已验证：验证动作 + 证据锚点 + 覆盖边界
- 未验证：缺口 + 风险 + 后续归属

## 第6节：收口落点与回写映射
- 对应 truth / phase / docs 的承载位
- 字段最小集与一致性检查点

## 第7节：争议处理与降级规则
- 证据不足或口径冲突时，统一降级为 `未验证 / 后续候选`
