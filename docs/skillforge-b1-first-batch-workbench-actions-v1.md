# SkillForge B1 第一批工作台动作方案（v1）

## 0. 文档目的与适用边界
本文档只服务于 B1 第一批运行中心工作台动作方案收口，不扩展到 B2/B3 的深编排、Skeleton 深能力、自动化与跨域治理能力。

- `docs/skillforge-b1-minimal-traceability-evidence-v1.md`

## 2. 第一批动作范围清单
### 2.1 必做
- PromptDraft / StepPlan 最小字段编辑与 Ready 状态到达
- 提交审批包前的最小检查摘要
- 提交包版本对与锁定范围显式确认
- 审批结论与执行入口的版本绑定显式化
- Run 详情最小追溯卡片与稳定回跳

### 2.2 可做
- 运行列表与运行详情中的轻量状态筛选 / 导航增强
- 任务详情侧的只读检查结果展示

### 2.3 明确不做
- 自动 prompt 生成
- 自动步骤拆解
- 自动策略优化
- 复杂可视化编排器
- 跨任务智能推荐
- Skeleton 评分推荐与跨域深联动

## 3. 最低闭环映射
### 可编辑
- PromptDraft 最小语义字段可维护
- StepPlan 最小步骤字段可维护

### 可提交
- 提交前完整性 / 一致性 / 来源 / 状态 / 变更 / 可追溯检查
- Ready → LockedForApproval 的确认节点可感知

### 可执行
- 审批通过版本与执行入口绑定
- 通过 / 驳回 / 补充的基础行为差异提示

### 可回看
- Run 详情可回看审批决策与执行事实关系
- Task ↔ PromptDraft ↔ StepPlan ↔ Approval ↔ Run 最小可见
- 审批完成后可稳定回跳到 run / task 语境

## 4. 关键断点与补位优先级
### P1
- 版本显式性不足
- 提交检查摘要挂载不足
- 执行入口与获准版本绑定不足

### P2
- 审批完成后的稳定回跳
- 运行详情中的四段链路追溯卡片

### P3
- 轻量状态筛选与任务详情提示增强

## 5. 最小证据位与版本锚点要求
- 状态位：对象状态、门禁状态、证据口径状态
- 版本位：PromptDraft / StepPlan 当前版本、审批获准版本、Run 消费版本
- 关系位：Task ↔ PromptDraft ↔ StepPlan ↔ Approval ↔ Run
- 检查摘要位：完整性 / 一致性 / 来源 / 状态 / 变更 / 可追溯

## 6. 实现前前提清单
- 冻结业务状态机与证据口径规则
- 冻结第一批动作边界清单
- 统一版本锚点与关系锚点命名口径
- 确认提交包与锁定语义
- 准备最小验收样本口径
- 约定审批 ↔ 运行中心回流路径

## 7. 风险与越界防线
- 不得把第一批动作方案写成“全量工作台完成”
- 不得把代码存在写成 happy path 已验证
- 不得提前承诺智能化、规模化复用与跨域深治理能力

## 8. 收口结论
B1 第一批应聚焦“最小可操作主链与可追溯补位”。当前已完成范围守门、动作面盘点、最小操作链、主链断点与追溯证据位定义，足以进入实现前负责人方案阶段。

当前可宣称的是：运行中心基础工作台路径已形成清晰方案；后续仍需在实现与验证中继续区分已实现、已验证与未验证范围。
