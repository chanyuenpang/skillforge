# SkillForge B6 范围与边界守门说明（配置与系统能力受控发布入口）

## A. 文档目的
本说明只用于 B6“配置与系统能力受控发布入口”的范围守门与口径统一。

## B. 适用范围 / 不适用范围
### 适用范围
- B6 入口描述
- 状态声明
- 证据挂载

### 不适用范围
- 实现设计
- 自动化扩展
- 后续阶段承诺

## C. B6 只解决的问题清单
- 范围收敛
- 边界声明
- 状态三分法
- 越界治理
- 争议回退机制

## D. 明确非目标
- 智能推荐、自动优化、自动血缘、智能影响分析
- 复杂审批策略引擎
- 跨任务 / 跨项目复杂治理图谱
- 运营级高级看板
- B7 / B8 / 阶段 C-D 能力前置承诺

## E. 状态口径规范
- 强制区分：`已实现 / 已验证 / 未验证`
- 每条结论必须带：证据锚点、覆盖边界、未覆盖范围
- 禁止把“代码存在 / 空数据闭环 / 分支实现”写成全量验证

## F. 越界表述禁用清单
- B6 完成后即具备智能推荐 / 自动优化能力
- 配置与系统能力已经全面可运营 / 可规模化治理
- 代码实现完成 = 能力交付完成
- 已实现 = 已验证
- 空数据闭环 = 业务样本全量验证完成
- 分支代码已实现 = happy path 实测完成

## G. 争议回退机制
- 证据不足或口径冲突时，统一降级为 `未验证 / 后续阶段候选`

## H. 与 B4 / B5 / roadmap 的对齐锚点
- B4：三段门禁与版本一致性
- B5：元数据与状态基线
- roadmap：阶段边界

## I. 结论模板
- 已实现：事实 + 锚点 + 未覆盖
- 已验证：动作 / 样本 + 锚点 + 覆盖边界
- 未验证：缺口 + 风险 + 阶段归属
