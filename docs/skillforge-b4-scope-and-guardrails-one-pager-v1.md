# SkillForge B4 范围与边界守门说明（审批与执行证据链）

## A. B4 目标一句话
本阶段仅固化“审批与执行证据链”的范围边界与状态口径，不新增超边界能力承诺。

## B. B4 纳入范围（In）
- 提交 → 审批 → 执行 → 回看 的问题域归档
- B2 版本锚点与审批-执行绑定叙事口径
- B3 `skeletonRef` 引用锚点与一致性检查口径（仅最小规则层）
- 文档间一致性修正（roadmap / truth / phase / spec）

## C. B4 排除范围（Out）
- 智能化、自动化、评分体系
- 跨域深治理与复杂追溯图谱
- 实现细节方案、接口设计、权限细则、策略引擎细则
- B5/B6/B7 的能力承诺

## D. 状态口径规则
- 统一采用：`已实现 / 已验证 / 未验证`
- 每条结论必须附证据锚点与未覆盖范围
- 不能用“文档已写”替代“能力已验证”
- 不能用“代码分支存在”替代“happy path 抽测通过”
- 不能用“空数据闭环成立”替代“真实业务样本验证完成”

## E. 高风险越界词黑名单
- B4 已完成审批执行全链路治理
- 版本追溯能力已全面验证
- Skeleton 闭环已完整落地（含质量评分 / 智能推荐）
- 运行中心已具备规模化治理能力
- 自动编排 / 自动优化已可用
- 代码已实现 = 功能已验证
- 规则已定义 = 线上可审计可回放
- 空数据闭环 = 真实样本闭环

## F. 发布前自检清单
- 是否出现“定义替代验证”
- 是否出现“代码替代证据”
- 是否遗漏未验证范围
- 是否把 B5+ 内容提前写入 B4

## G. 对外表述落点
只报告“当前证据成立范围 + 未验证边界 + 下一步待证事项”，不做跨阶段承诺。
