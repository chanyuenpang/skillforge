# SkillForge C0 入口守门与阶段边界锁定（v1）

## 0. 文档定位与非目标
本文只用于 C0 入口守门与阶段边界锁定，不做第二阶段退出裁决，不做第三阶段准入裁决，也不写实现方案。

## 1. 输入依据与适用范围
- `docs/skillforge-roadmap-and-doc-governance-v1.md`
- `docs/skillforge-b8-owner-closeout-criteria-v1.md`
- `docs/skillforge-b8-phase-c-entry-framework-v1.md`
- `docs/skillforge-b8-boundary-freeze-and-banlist-review-v1.md`
- `docs/skillforge-b8-sync-and-close-memo-v1.md`
- `tasks/skillforge-第三阶段主计划/plan.json`

## 2. C0 核心守门问题定义
- 入口依据 ≠ 入口成立
- 只允许在已覆盖样本与链路范围内成立
- 先守门，再推进

## 3. 启动前提最小集（Checklist）
- 事实底稿一致性
- 最小验证输入已成立
- 基线守门输入存在
- 治理红线输入明确
- 未覆盖风险输入保留
- 权限边界输入明确

## 4. 判定语义分层与触发条件
### 可进入
具备负责人裁决最低依据集，且仅在覆盖范围内成立。

### 有条件进入
依据基本具备，但必须绑定前置条件（基线回归、补证）。

### 暂不进入
关键输入缺失或口径冲突。

### 降级进入
仅允许低风险准备动作，不得宣称阶段切换或实质执行启动。

## 5. 边界冻结清单
- 不把 B8 收口写成第二阶段正式退出
- 不把入口依据写成第三阶段已进入 / 已批准执行
- 不把最小样本验证写成全量可运营
- 不把空数据闭环、分支实现、命令样例写成全面 happy path 完成
- 不承诺自动联调、自动修复、自动回滚、自动推荐 / 分析
- 不承诺跨任务 / 跨项目深治理图谱
- 不承诺 Skeleton 高阶评分与推荐联动
- 不承诺规模化稳定性与复杂异常恢复能力
- C0 文档不替代 spec / ADR / 子计划
- 仅做最小回写，不宣告能力跃迁

## 6. 禁词与降调词典
### 禁用
- 第二阶段正式结束 / 正式退出（已确认）
- 第三阶段已进入 / 入口已确认 / 已获批准执行
- 全面可运营 / 全链路已验证 / 全量 happy path 完成
- 自动修复 / 自动回滚 / 自动推荐已上线（可签收）
- B8 已完成全部交付，可直接规模化推广
- 代码已实现 = 能力已验证

### 降调
- 已完成 → 在文档治理层或最小样本范围内已实现并有证据
- 已验证 → 仅限已记录样本与链路范围
- 可复用 → 规则 / 模板可复用，实现效果待规模验证
- 可推广 → 具备继续推进条件，推广需补证据
- 可进入下一阶段 → 已具备入口判断依据（限已覆盖范围），是否进入待负责人裁决

## 7. 回退与纠偏机制
出现以下情况统一回退为 `候选 / 条件化 / 未验证`：
- 证据不可追溯
- 覆盖与结论不匹配
- 文档冲突
- 忽略未覆盖风险
- 边界越权

## 8. 判定记录模板（留裁决位）
- 结论
- 证据锚点
- 覆盖范围
- 未覆盖项
- 负责人裁决位

## 9. 最小回写要求
- 仅同步 roadmap / truth / phase 的最小口径项
- 禁止扩写为阶段切换公告

## 10. 固定边界句
已具备负责人裁决所需的基础输入，但裁决位保持开放。
