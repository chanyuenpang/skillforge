# SkillForge B2 最小样本验证与口径标注说明（v1）

## 5.1 目的与边界
本文只定义 B2 的最小样本验证与口径标注规则，不等于全量测试计划，也不外推为规模化验证完成。

## 5.2 验证对象清单

- StepPlan

- 版本绑定
- Run 回看追溯链

## 5.3 最小样本场景矩阵
### 场景A：编排独立入口到提交锁定主链
- 覆盖：进入独立入口 → PromptDraft ReadyForPlan → StepPlan ReadyForApproval → 提交前检查摘要 → 提交并锁定到 `LockedForApproval`
- 判据：证明“可编辑 + 可提交 + 有门禁”的最小闭环真实成立

### 场景B：门禁失败与阻断可见性
- 覆盖：完整性缺失 / 一致性冲突 / 来源缺失 / 未 Ready 导致不可提交
- 判据：证明门禁真实生效，而不是只有规则文档

### 场景C：关键字段变更后的待同步确认阻断
- 覆盖：PromptDraft 关键字段变更后，StepPlan 未同步确认时禁止锁定提交
- 判据：证明变更门禁生效

### 场景D：锁定后版本纪律
- 覆盖：`LockedForApproval` 后不可无痕覆写，只能新修订版本再走审批绑定
- 判据：证明版本纪律与审计可解释性成立

### 场景E：审批-执行最小绑定与回看链
- 覆盖：`approvedPackageRef` 与 Run 消费版本一致；Run 可回看 `Run -> Approval -> StepPlan@v -> PromptDraft@v -> Task`
- 判据：证明版本锚点链存在且可追

## 5.4 状态判定规则
### 已实现
- 路由、对象字段、状态机、门禁规则已接入代码 / 配置
- 回链入口、提示文案、绑定字段已存在
- 但尚未完成独立抽测或真实样本验证

### 已验证
- 至少一条真实样本走通主链
- 至少一条负向门禁样本被真实拦截
- 至少一条版本一致性样本可证伪
- 可回溯到 `taskRef / version / updatedAt / approvalRef / runId`

### 未验证
- 代码已实现但尚未抽测
- 仅空数据闭环，未覆盖业务样本 happy path
- 仅验证 UI 可见，未验证提交门禁 / 版本绑定生效

## 5.7 禁用表述黑名单
- 最小样本验证 = 全量场景验证 / 全面验证完成
- 代码已实现 / 文档已定义 = 稳定支撑生产级编排

- 单条样本通过 = 可规模化运营 / 可推广
- 版本链可定义 = 跨域深追溯治理已完成
- B2 编排基础能力 = 已具备智能编排 / 自动优化 / 自动推荐
