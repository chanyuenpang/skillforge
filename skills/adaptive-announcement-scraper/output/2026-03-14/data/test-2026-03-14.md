## 跨站点发现总结

### 共同特征
1. **URL模式**: 公告链接通常包含 `/xxgk/tzgg/` 或 `/xygk/tzgg/`
2. **时间戳格式**: `/202602/t20260210_2981101.htm` (年年月/年月日_数字.htm)
3. **容器类名**: `.main`, `.clearflx`, `.list` 在多个站点出现

### 推荐的自适应策略

```javascript
// 自适应公告提取策略
const strategies = [
  // 策略1: 查找 .main 容器内的公告链接
  {
    selector: '.main a[href*="/xxgk/tzgg"], .main a[href*="/xygk/tzgg"]',
    weight: 10
  },
  // 策略2: 查找 .list 容器
  {
    selector: '.list a[href*="/tzgg/"]',
    weight: 8
  },
  // 策略3: 查找包含特定URL模式的链接
  {
    selector: 'a[href*="/xxgk/tzgg/"], a[href*="/xygk/tzgg/"]',
    weight: 5
  },
  // 策略4: 基于URL时间戳模式的链接
  {
    selector: 'a[href*="/202"][href$=".htm"]',
    filter: (href) => /\/tzgg\//.test(href),
    weight: 3
  }
];
```
