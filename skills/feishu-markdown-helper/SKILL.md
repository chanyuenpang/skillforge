# 飞书Markdown富文本优化技能
适配无卡片权限的飞书环境，无需卡片即可展示格式整洁的富文本内容。

## 核心规则
### 1. 自动触发场景
- 所有飞书消息发送场景，只要内容包含Markdown格式自动触发
- 自动兼容测试企业/无卡片权限的环境，不需要手动切换
- 输出格式为飞书原生post富文本，所有飞书版本均支持，无权限限制

### 2. 支持的Markdown语法（100%兼容渲染）
| 语法类型 | 支持情况 | 渲染效果 |
|---------|----------|----------|
| 标题（#/##/###） | ✅ 完全支持 | 自动转换为不同字号的加粗标题 |
| 加粗（**内容**） | ✅ 完全支持 | 飞书原生加粗样式 |
| 斜体（*内容*） | ✅ 完全支持 | 飞书原生斜体样式 |
| 代码块（```代码```） | ✅ 完全支持 | 自动添加灰色背景、等宽字体，保留换行缩进 |
| 行内代码（`代码`） | ✅ 完全支持 | 等宽字体、灰色背景 |
| 有序/无序列表 | ✅ 完全支持 | 自动识别层级，保留缩进 |
| 表格（\|列1\|列2\|） | ✅ 完全支持 | 自动转换为飞书原生表格，边框对齐 |
| 链接（[文本](URL)） | ✅ 完全支持 | 可点击跳转的蓝色链接 |
| @用户（@用户名） | ✅ 完全支持 | 自动识别@用户，飞书原生@提醒效果 |
| 分割线（---） | ✅ 完全支持 | 飞书原生分割线 |
| Emoji（🎉） | ✅ 完全支持 | 原生emoji渲染 |
| 引用（> 内容） | ✅ 完全支持 | 灰色竖线引用样式 |

### 3. 最佳实践
#### 发送消息统一使用`sendMessageFeishu`API（无需卡片权限）
```typescript
import { sendMessageFeishu } from "../../src/send.js";

await sendMessageFeishu({
  cfg: 飞书配置对象,
  to: 接收目标ID,
  text: `## 测试标题
**加粗内容**
这是普通文本，包含行内代码：\`const a = 1;\`

\`\`\`typescript
// 代码块示例
function test() {
  console.log("hello world");
}
\`\`\`

| 功能 | 支持 |
|------|------|
| 表格 | ✅ |
| 列表 | ✅ |

- 无序列表项1
- 无序列表项2
  - 子列表项

> 引用内容示例

[跳转链接](https://open.feishu.cn)
`,
  replyToMessageId: "触发消息ID", // 可选：回复指定消息
  replyInThread: true, // 可选：话题群自动进入线程
  mentions: [{ id: "ou_xxx", name: "张三" }] // 可选：@用户列表
})
```

### 4. 自动优化规则
- 长代码块自动添加滚动条，不会超出屏幕宽度
- 表格自动调整列宽，内容自动换行
- 多余空行自动压缩，保持排版整洁
- 长链接自动缩短显示，不影响跳转
- @用户自动高亮，触发飞书提醒

### 5. 颜色强调补充
- 如需在当前回复 / Feishu markdown 中做颜色强调，查阅同目录文档：`./FEISHU_COLOR_USAGE.md`
- 该文档包含已验证可用的 `<font color=...>文本</font>` 写法、可用颜色枚举值，以及避坑说明

### 6. 禁用操作
- 禁止手动转义Markdown特殊字符，直接传入原始Markdown文本即可
- 禁止手动拼接富文本格式，自动转换更可靠
- 禁止发送过于复杂的嵌套表格，建议拆分多个简单表格展示
