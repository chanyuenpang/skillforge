# 游戏更新可视化

将游戏项目的 git 提交记录转化为生动的分镜式漫画长图，适合手机浏览和社交媒体传播。

## 工作流程

### 第一步：获取更新记录

1. 进入项目目录，获取最近一周的 git 提交：
   ```bash
   git log --since="1 week ago" --pretty=format:"%h|%s|%ad" --date=short
   ```

2. 分类整理更新内容：
   - ✨ 新功能 (feat)
   - 🔧 改进优化 (refactor, perf)
   - 🐛 修复 (fix)
   - 📚 文档 (docs)
   - 🔧 其他 (chore, style)

### 第二步：编写分镜脚本

**必须**先编写分镜脚本，用户确认后再生成图片。

脚本结构：
```markdown
## 第N张：[标题]

### 画面布局
- 分镜格数（通常4格）
- 每格占比

### 分镜内容
- 第1格：标题区（爆炸对话框）
- 第2格：问题/背景
- 第3格：解决方案/功能详解
- 第4格：总结区

### 配色方案
- 主色
- 强调色
```

### 第三步：确定角色形象

根据游戏类型确定角色形象：

| 游戏类型 | 角色形象示例 |
|---------|-------------|
| 修仙/武侠 | 道士、剑修、长老、杂役弟子 |
| 二次元 | Q版萌系角色 |
| 科幻 | 宇航员、机器人、未来战士 |
| 奇幻 | 法师、骑士、精灵、兽人 |
| 现代/都市 | 上班族、学生、职业角色 |

### 第四步：生成图片

使用 ImageGen 生成，参数：
- 尺寸：9:16 竖版（推荐 768x1024 或 768x1344）
- 风格：理解漫画风格（类似"混知""不会画出版社"）
- 特征：粗黑线条、夸张表情、分镜布局

### 第五步：拼接长图

使用 Python PIL 拼接：
```python
from PIL import Image

images = [Image.open(f) for f in image_files]
total_height = sum(img.height for img in images)
max_width = max(img.width for img in images)

result = Image.new('RGB', (max_width, total_height), (255, 255, 255))
y_offset = 0
for img in images:
    x_offset = (max_width - img.width) // 2
    result.paste(img, (x_offset, y_offset))
    y_offset += img.height

result.save('update-full.png')
```

## 图片数量建议

| 更新量 | 建议张数 | 结构 |
|-------|---------|------|
| 少量（<10提交） | 4张 | 封面+2功能+总结 |
| 中等（10-20提交） | 5-6张 | 封面+3-4功能+总结 |
| 大量（>20提交） | 7-8张 | 封面+5-6功能+总结 |

**上限：不超过8张**，避免长图过长。

## 分镜脚本模板

```markdown
## 第1张：封面图

**顶部**：爆炸对话框标题 "[游戏名] 周更新" + 日期
**中间**：主角形象 + 游戏元素漂浮
**底部**：数据卡片（提交数、新功能数、文档更新数）

## 第2-N张：功能详情（每张一个功能）

**第1格**：爆炸对话框 "✨ 新功能：[功能名]"
**第2格**：问题/背景场景
**第3格**：功能详解（左右分栏或图文结合）
**第4格**：底部总结横幅

## 最后1张：总结

**顶部**：奖杯/成就图标 + "本周战绩"
**中间**：庆祝场景 + 角色欢呼
**底部**：数据汇总 + 项目分支名 + 感谢语
```

## 提示词模板

### 风格前缀（每张图必须包含）
```
理解漫画风格信息图，类似"混知"或"不会画出版社"的科普漫画风格。

画风特征：
- 粗黑线条轮廓，清晰有力
- 人物表情夸张生动，动作幅度大
- 色彩鲜明，饱和度适中
- 爆炸对话框、箭头、强调框丰富
```

### 内容描述
```
竖版手机长条图（9:16比例），[N]格分镜。

第1格（标题区）：...
第2格（...）：...
...
```

### 配色说明
```
配色：[主色]主色，[强调色]强调，[辅助色]辅助。
```

### 输出规范
```
输出规范：9:16竖版，768px宽，中文标注，[风格]漫画风格。
```

## 最佳实践

1. **先脚本后生成** - 避免反复生成浪费资源
2. **渐进式确认** - 每轮迭代都先确认再继续
3. **风格统一** - 所有图片保持相同画风和角色形象
4. **叙事清晰** - 每格分镜有明确的信息传递
5. **留白适度** - 保持呼吸感，不堆砌信息
